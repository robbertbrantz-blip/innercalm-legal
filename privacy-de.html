4. Wie wir Ihre Daten speichern

Ihre personenbezogenen Daten werden lokal auf Ihrem Gerät gespeichert. Wenn Sie iCloud aktiviert haben, können Ihre Daten über iCloud mit Ihren anderen Apple-Geräten synchronisiert werden. Wir speichern Ihre personenbezogenen Daten nicht auf unseren Servern.

4.1 Lokale Speicherung

Alle Chat-Nachrichten, Tagebucheinträge, Stimmungsdaten und Gesprächszusammenfassungen werden lokal auf Ihrem Gerät mit sicherer On-Device-Speicherung gespeichert. Das bedeutet, dass Ihre Daten bei Ihnen bleiben und nicht auf einen von uns kontrollierten Server hochgeladen werden.

4.2 iCloud-Synchronisierung

Wenn Sie iCloud auf Ihrem Gerät aktiviert haben, können Ihre InnerCalm+-Daten über Apples iCloud-Dienst zwischen Ihren Apple-Geräten synchronisiert werden. Diese Synchronisierung unterliegt Apples eigener Datenschutzrichtlinie und Nutzungsbedingungen. Wir haben keinen Zugriff auf Ihre in iCloud gespeicherten Daten. Sie können die iCloud-Synchronisierung für InnerCalm+ in Ihren Geräteeinstellungen > [Ihr Name] > iCloud deaktivieren.

4.3 Datenaufbewahrung

Da Ihre Daten lokal (und optional in iCloud) gespeichert werden, haben Sie volle Kontrolle über die Aufbewahrung. Sie können Ihre Daten jederzeit löschen, indem Sie die App löschen oder App-Daten in Ihren Geräteeinstellungen löschen. Gesprächsdaten, die zur Verarbeitung an OpenAI gesendet werden, werden von InnerCalm+ nach Erhalt der Antwort nicht auf einem Server gespeichert.

5. Drittanbieter-KI-Dienst: OpenAI

WICHTIG: InnerCalm+ sendet bestimmte personenbezogene Daten an den GPT-Dienst von OpenAI, um KI-gestützte Funktionen bereitzustellen. Dieser Abschnitt erklärt genau, was geteilt wird, warum und welche Schutzmaßnahmen vorhanden sind.

5.1 Welche Daten an OpenAI gesendet werden

Wenn Sie KI-gestützte Funktionen in InnerCalm+ nutzen, können die folgenden Daten an die API von OpenAI übertragen werden:

  • Ihre Chat-Nachrichten: der Text, den Sie während einer KI-Gesprächssitzung eingeben
  • Ihre Stimmungs- und Emotionsdaten: die Stimmungsbewertungen oder emotionalen Beschreibungen, die Sie angegeben haben, um der KI Kontext für eine relevantere Antwort zu geben
  • Gesprächszusammenfassungen: Zusammenfassungen, die aus Ihrer vorherigen Gesprächshistorie generiert wurden, damit die KI den Kontext zwischen Sitzungen beibehalten kann

5.2 Wer diese Daten erhält

Anbieter: OpenAI, L.L.C.
Dienst: OpenAI API (GPT-Sprachmodell)
Standort: Vereinigte Staaten
Website: https://openai.com

5.3 Zweck der Datenweitergabe

Daten werden ausschließlich für die folgenden Zwecke an OpenAI gesendet:

  • Um personalisierte KI-Antworten auf Ihre Nachrichten und Reflexionen zu generieren
  • Um kontextuell relevante Wellness-Anleitungen basierend auf Ihrem emotionalen Zustand und Ihrer Gesprächshistorie bereitzustellen
  • Um Gesprächszusammenfassungen zu erstellen, die die Kontinuität Ihrer Erfahrung verbessern

5.4 Datenverarbeitung durch OpenAI

Aspekt Details
Werden Daten für Modelltraining verwendet? Nein. Wir nutzen die API von OpenAI mit Datennutzungsrichtlinien, die sicherstellen, dass Ihre Daten NICHT verwendet werden, um die Modelle von OpenAI zu trainieren oder zu verbessern.
Datenspeicherung durch OpenAI OpenAI kann API-Eingaben bis zu 30 Tage zur Missbrauchsüberwachung aufbewahren, danach werden sie gelöscht. OpenAI speichert Ihre Daten nicht für längerfristige Zwecke.
Verschlüsselung bei Übertragung Ja. Alle an OpenAI übertragenen Daten werden mit TLS (Transport Layer Security) verschlüsselt.
Datenverarbeitungsvereinbarung Unsere Nutzung der OpenAI-API unterliegt dem Data Processing Agreement (DPA) und den API-Nutzungsbedingungen von OpenAI, die Schutzmaßnahmen bieten, die den in dieser Richtlinie beschriebenen gleichwertig oder überlegen sind.
Unterauftragsverarbeiter OpenAI kann Unterauftragsverarbeiter (wie Microsoft Azure) nutzen, um seine Dienste bereitzustellen. Details sind in der Datenschutzdokumentation von OpenAI verfügbar.

5.5 Ihre Einwilligung

Bevor personenbezogene Daten an OpenAI gesendet werden, zeigt InnerCalm+ Ihnen einen deutlichen Einwilligungsbildschirm, der:

  • Erklärt, dass Ihre Daten an den GPT-Dienst von OpenAI gesendet werden
  • Beschreibt, welche spezifischen Daten geteilt werden (Chat-Nachrichten, Stimmungsdaten, Gesprächszusammenfassungen)
  • Erfordert, dass Sie durch Tippen auf „Mit KI fortfahren" explizit einwilligen, bevor Daten übertragen werden
  • Ihnen ermöglicht, abzulehnen und trotzdem Nicht-KI-Funktionen der App zu nutzen

Sie können Ihre Einwilligung jederzeit über die Einstellungen der App widerrufen. Wenn Sie Ihre Einwilligung widerrufen, werden keine weiteren Daten an OpenAI gesendet.
