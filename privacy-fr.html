Politique de confidentialité

Dernière mise à jour : 27 février 2026

Cette politique de confidentialité est conçue pour être conforme aux directives de révision de l'App Store d'Apple 5.1.1(i) et 5.1.2(i), au Règlement général sur la protection des données (RGPD) de l'UE et au California Consumer Privacy Act (CCPA).

Innercalm utilise le service GPT d'OpenAI pour alimenter les fonctionnalités basées sur l'IA. Cette politique explique exactement quelles données sont partagées, comment elles sont utilisées et comment vous gardez le contrôle.

1. Introduction

Innercalm (« nous », « notre » ou « l'Application ») est une application de bien-être et de pleine conscience qui aide les utilisateurs à réfléchir sur leurs émotions, à suivre leur bien-être mental et à participer à une auto-réflexion guidée par des conversations alimentées par l'IA.

Nous nous engageons à protéger votre vie privée. Cette politique explique en termes clairs et spécifiques quelles données personnelles nous collectons, comment nous les collectons, ce que nous en faisons et avec qui nous les partageons — y compris notre utilisation de services d'intelligence artificielle (IA) tiers.

Nous collectons et traitons les catégories suivantes de données personnelles :

4. Comment nous stockons vos données

Vos données personnelles sont stockées localement sur votre appareil. Si vous avez activé iCloud, vos données peuvent être synchronisées via iCloud vers vos autres appareils Apple. Nous ne stockons pas vos données personnelles sur nos serveurs.

4.1 Stockage local

Tous les messages de chat, entrées de journal, données d'humeur et résumés de conversation sont stockés localement sur votre appareil en utilisant un stockage sécurisé sur l'appareil. Cela signifie que vos données restent avec vous et ne sont pas téléchargées vers un serveur que nous contrôlons.

4.2 Synchronisation iCloud

Si vous avez activé iCloud sur votre appareil, vos données Innercalm peuvent être synchronisées entre vos appareils Apple via le service iCloud d'Apple. Cette synchronisation est régie par la propre politique de confidentialité et les conditions d'Apple. Nous n'avons pas accès à vos données stockées dans iCloud. Vous pouvez désactiver la synchronisation iCloud pour Innercalm dans les paramètres de votre appareil > [votre nom] > iCloud.

4.3 Conservation des données

Comme vos données sont stockées localement (et optionnellement dans iCloud), vous avez un contrôle total sur la conservation. Vous pouvez supprimer vos données à tout moment en supprimant l'application ou en effaçant les données de l'application dans les paramètres de votre appareil. Les données de conversation envoyées à OpenAI pour traitement ne sont pas stockées par Innercalm sur aucun serveur après réception de la réponse.

5. Service IA tiers : OpenAI

IMPORTANT : Innercalm envoie certaines données personnelles au service GPT d'OpenAI pour fournir des fonctionnalités alimentées par l'IA. Cette section explique exactement ce qui est partagé, pourquoi et quelles protections sont en place.

5.1 Quelles données sont envoyées à OpenAI

Lorsque vous utilisez des fonctionnalités alimentées par l'IA dans Innercalm, les données suivantes peuvent être transmises à l'API d'OpenAI :

  • Vos messages de chat : le texte que vous tapez lors d'une session de conversation IA
  • Vos données d'humeur et d'émotion : les évaluations d'humeur ou descripteurs émotionnels que vous avez fournis, pour donner à l'IA un contexte pour une réponse plus pertinente
  • Résumés de conversation : résumés générés à partir de votre historique de conversation précédent, afin que l'IA puisse maintenir le contexte entre les sessions

5.2 Qui reçoit ces données

Fournisseur : OpenAI, L.L.C.
Service : API OpenAI (modèle de langage GPT)
Localisation : États-Unis
Site web : https://openai.com

5.3 Objectif du partage de données

Les données sont envoyées à OpenAI uniquement pour les objectifs suivants :

  • Pour générer des réponses IA personnalisées à vos messages et réflexions
  • Pour fournir des conseils de bien-être contextuellement pertinents basés sur votre état émotionnel et votre historique de conversation
  • Pour créer des résumés de conversation qui améliorent la continuité de votre expérience

5.4 Traitement des données par OpenAI

Aspect Détails
Données utilisées pour l'entraînement du modèle ? Non. Nous utilisons l'API d'OpenAI avec des politiques d'utilisation des données qui garantissent que vos données ne sont PAS utilisées pour entraîner ou améliorer les modèles d'OpenAI.
Conservation des données par OpenAI OpenAI peut conserver les entrées API jusqu'à 30 jours pour la surveillance des abus, après quoi elles sont supprimées. OpenAI ne stocke pas vos données à des fins à plus long terme.
Chiffrement en transit Oui. Toutes les données transmises à OpenAI sont chiffrées en utilisant TLS (Transport Layer Security).
Accord de traitement des données Notre utilisation de l'API d'OpenAI est régie par l'Accord de traitement des données (DPA) et les Conditions d'utilisation de l'API d'OpenAI, qui fournissent des protections équivalentes ou supérieures à celles décrites dans cette politique.
Sous-traitants OpenAI peut utiliser des sous-traitants (comme Microsoft Azure) pour fournir ses services. Les détails sont disponibles dans la documentation de confidentialité d'OpenAI.

5.5 Votre consentement

Avant que des données personnelles ne soient envoyées à OpenAI, Innercalm vous présentera un écran de consentement clair qui :

  • Explique que vos données seront envoyées au service GPT d'OpenAI
  • Décrit quelles données spécifiques seront partagées (messages de chat, données d'humeur, résumés de conversation)
  • Vous demande d'accepter explicitement en appuyant sur « Continuer avec l'IA » avant que des données ne soient transmises
  • Vous permet de refuser et d'utiliser quand même les fonctionnalités non-IA de l'application

Vous pouvez retirer votre consentement à tout moment via les Paramètres de l'application. Si vous retirez votre consentement, aucune donnée supplémentaire ne sera envoyée à OpenAI.

6. Données que nous ne partageons ni ne vendons

Nous ne vendons, ne louons ni n'échangeons vos données personnelles à des tiers.

Nous ne partageons pas vos données avec des annonceurs, des courtiers en données ou des sociétés d'analyse.

Le seul tiers qui reçoit des données personnelles d'Innercalm est OpenAI, uniquement dans le but d'alimenter les fonctionnalités IA comme décrit dans la Section 5, et seulement après que vous ayez donné votre consentement explicite.

8. Vie privée des enfants

Innercalm n'est pas destiné aux enfants de moins de 13 ans (ou 16 ans dans l'UE/EEE). Nous n'autorisons pas sciemment les enfants à utiliser nos fonctionnalités alimentées par l'IA, qui transmettent des données à OpenAI pour traitement. Nous ne stockons pas de données personnelles sur nos serveurs — toutes les données utilisateur restent sur l'appareil de l'utilisateur et, si activé, dans iCloud. Si vous pensez qu'un enfant a utilisé nos fonctionnalités IA, veuillez nous contacter afin que nous puissions vous conseiller sur les mesures appropriées.

9. Transferts internationaux de données

Lorsque vous utilisez les fonctionnalités IA, vos données sont transmises aux serveurs d'OpenAI, qui sont situés aux États-Unis. Si vous êtes situé dans l'UE/EEE, cela constitue un transfert international de données. Ce transfert est effectué sous des garanties appropriées, y compris l'Accord de traitement des données d'OpenAI et les Clauses contractuelles types (CCT) le cas échéant.

10. Mesures de sécurité

Nous mettons en œuvre des mesures techniques et organisationnelles appropriées pour protéger vos données personnelles :

  • Toutes les données stockées localement sur votre appareil sont protégées par les fonctionnalités de sécurité de votre appareil (code d'accès, Face ID, Touch ID)
  • Toutes les données transmises à OpenAI sont chiffrées en utilisant TLS pendant le transit
  • Nous utilisons l'API d'OpenAI avec des politiques de traitement des données de niveau entreprise qui empêchent vos données d'être utilisées pour l'entraînement du modèle
  • Nous ne maintenons aucune base de données côté serveur contenant vos données personnelles
