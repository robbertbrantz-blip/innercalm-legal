Política de Privacidad

Última actualización: 27 de febrero de 2026

Esta política de privacidad está diseñada para cumplir con las Directrices de Revisión del App Store de Apple 5.1.1(i) y 5.1.2(i), el Reglamento General de Protección de Datos (RGPD) de la UE y la Ley de Privacidad del Consumidor de California (CCPA).

Innercalm utiliza el servicio GPT de OpenAI para impulsar las funciones basadas en IA. Esta política explica exactamente qué datos se comparten, cómo se utilizan y cómo mantienes el control.

1. Introducción

Innercalm ("nosotros", "nuestro" o "la Aplicación") es una aplicación de bienestar y mindfulness que ayuda a los usuarios a reflexionar sobre sus emociones, seguir su bienestar mental y participar en autorreflexión guiada a través de conversaciones impulsadas por IA.

Estamos comprometidos con la protección de tu privacidad. Esta política explica en términos claros y específicos qué datos personales recopilamos, cómo los recopilamos, qué hacemos con ellos y con quién los compartimos — incluyendo nuestro uso de servicios de inteligencia artificial (IA) de terceros.

Recopilamos y procesamos las siguientes categorías de datos personales:

Categoría de datos Ejemplos Cómo se recopilan
Mensajes de chat y entradas de diario Texto que escribes durante conversaciones de IA y reflexiones de diario Directamente de ti, cuando usas la función de chat o diario
Datos de estado de ánimo y emociones Valoraciones de estado de ánimo, etiquetas de emociones, indicadores de estado emocional que seleccionas o describes Directamente de ti, cuando registras tu estado de ánimo o describes sentimientos

4. Cómo almacenamos tus datos

Tus datos personales se almacenan localmente en tu dispositivo. Si tienes iCloud habilitado, tus datos pueden sincronizarse a través de iCloud con tus otros dispositivos Apple. No almacenamos tus datos personales en nuestros servidores.

4.1 Almacenamiento local

Todos los mensajes de chat, entradas de diario, datos de estado de ánimo y resúmenes de conversación se almacenan localmente en tu dispositivo usando almacenamiento seguro en el dispositivo. Esto significa que tus datos permanecen contigo y no se suben a ningún servidor controlado por nosotros.

4.2 Sincronización de iCloud

Si tienes iCloud habilitado en tu dispositivo, tus datos de Innercalm pueden sincronizarse entre tus dispositivos Apple a través del servicio iCloud de Apple. Esta sincronización está regida por la propia política de privacidad y términos de Apple. No tenemos acceso a tus datos almacenados en iCloud. Puedes desactivar la sincronización de iCloud para Innercalm en la configuración de tu dispositivo > [tu nombre] > iCloud.

4.3 Retención de datos

Debido a que tus datos se almacenan localmente (y opcionalmente en iCloud), tienes control total sobre la retención. Puedes eliminar tus datos en cualquier momento eliminando la aplicación o borrando los datos de la aplicación en la configuración de tu dispositivo. Los datos de conversación enviados a OpenAI para procesamiento no son almacenados por Innercalm en ningún servidor después de recibir la respuesta.

5. Servicio de IA de terceros: OpenAI

IMPORTANTE: Innercalm envía ciertos datos personales al servicio GPT de OpenAI para proporcionar funciones impulsadas por IA. Esta sección explica exactamente qué se comparte, por qué y qué protecciones están implementadas.

5.1 Qué datos se envían a OpenAI

Cuando usas funciones impulsadas por IA en Innercalm, los siguientes datos pueden transmitirse a la API de OpenAI:

  • Tus mensajes de chat: el texto que escribes durante una sesión de conversación de IA
  • Tus datos de estado de ánimo y emociones: las valoraciones de estado de ánimo o descriptores emocionales que has proporcionado, para dar a la IA contexto para una respuesta más relevante
  • Resúmenes de conversación: resúmenes generados de tu historial de conversación anterior, para que la IA pueda mantener el contexto entre sesiones

5.2 Quién recibe estos datos

Proveedor: OpenAI, L.L.C.
Servicio: API de OpenAI (modelo de lenguaje GPT)
Ubicación: Estados Unidos
Sitio web: https://openai.com

5.3 Propósito del intercambio de datos

Los datos se envían a OpenAI únicamente para los siguientes propósitos:

  • Para generar respuestas de IA personalizadas a tus mensajes y reflexiones
  • Para proporcionar orientación de bienestar contextualmente relevante basada en tu estado emocional e historial de conversación
  • Para crear resúmenes de conversación que mejoren la continuidad de tu experiencia

5.4 Manejo de datos por OpenAI

Aspecto Detalles
¿Se usan los datos para entrenar modelos? No. Usamos la API de OpenAI con políticas de uso de datos que aseguran que tus datos NO se utilizan para entrenar o mejorar los modelos de OpenAI.
Retención de datos por OpenAI OpenAI puede retener las entradas de API hasta 30 días para monitoreo de abusos, después de lo cual se eliminan. OpenAI no almacena tus datos para propósitos a largo plazo.
Cifrado en tránsito Sí. Todos los datos transmitidos a OpenAI están cifrados usando TLS (Transport Layer Security).
Acuerdo de procesamiento de datos Nuestro uso de la API de OpenAI está regido por el Acuerdo de Procesamiento de Datos (DPA) y los Términos de Uso de la API de OpenAI, que proporcionan protecciones equivalentes o superiores a las descritas en esta política.
Subprocesadores OpenAI puede usar subprocesadores (como Microsoft Azure) para proporcionar sus servicios. Los detalles están disponibles en la documentación de privacidad de OpenAI.

5.5 Tu consentimiento

Antes de que cualquier dato personal se envíe a OpenAI, Innercalm te presentará una pantalla de consentimiento clara que:

  • Explica que tus datos se enviarán al servicio GPT de OpenAI
  • Describe qué datos específicos se compartirán (mensajes de chat, datos de estado de ánimo, resúmenes de conversación)
  • Requiere que aceptes explícitamente tocando "Continuar con IA" antes de que se transmitan datos
  • Te permite rechazar y aún así usar las funciones no-IA de la aplicación

Puedes retirar tu consentimiento en cualquier momento a través de la Configuración de la aplicación. Si retiras tu consentimiento, no se enviarán más datos a OpenAI.

6. Datos que no compartimos ni vendemos

No vendemos, alquilamos ni intercambiamos tus datos personales con terceros.

No compartimos tus datos con anunciantes, corredores de datos o empresas de análisis.

El único tercero que recibe datos personales de Innercalm es OpenAI, únicamente con el propósito de impulsar las funciones de IA como se describe en la Sección 5, y solo después de que hayas dado tu consentimiento explícito.

8. Privacidad de los niños

Innercalm no está dirigido a niños menores de 13 años (o 16 años en la UE/EEE). No permitimos conscientemente que los niños utilicen nuestras funciones impulsadas por IA, que transmiten datos a OpenAI para su procesamiento. No almacenamos datos personales en nuestros servidores — todos los datos del usuario permanecen en el dispositivo del usuario y, si está habilitado, en iCloud. Si crees que un niño ha utilizado nuestras funciones de IA, por favor contáctanos para que podamos asesorarte sobre los pasos apropiados.

9. Transferencias internacionales de datos

Cuando usas funciones de IA, tus datos se transmiten a los servidores de OpenAI, que están ubicados en Estados Unidos. Si te encuentras en la UE/EEE, esto constituye una transferencia internacional de datos. Esta transferencia se realiza bajo salvaguardas apropiadas, incluyendo el Acuerdo de Procesamiento de Datos de OpenAI y las Cláusulas Contractuales Estándar (CCE) según corresponda.

10. Medidas de seguridad

Implementamos medidas técnicas y organizativas apropiadas para proteger tus datos personales:

  • Todos los datos almacenados localmente en tu dispositivo están protegidos por las características de seguridad de tu dispositivo (código de acceso, Face ID, Touch ID)
  • Todos los datos transmitidos a OpenAI están cifrados usando TLS durante el tránsito
  • Usamos la API de OpenAI con políticas de manejo de datos de nivel empresarial que evitan que tus datos se usen para entrenamiento de modelos
  • No mantenemos ninguna base de datos del lado del servidor que contenga tus datos personales

11. Cambios a esta política

Podemos actualizar esta política de privacidad de vez en cuando. Cuando hagamos cambios significativos, te notificaremos a través de la Aplicación o por otros medios apropiados. La fecha "Última actualización" en la parte superior de esta política indica cuándo se hicieron los cambios más recientes.
